Digital Skill Passport

Digital Skill Passport is a web-based platform designed to help students maintain and showcase their skills, projects, certifications, workshops, internships, and achievements in one organized digital profile. It provides a structured alternative to maintaining these details separately in a traditional résumé.

Technologies Used
* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Local Server: XAMPP
* Email/Password Recovery: PHPMailer
* Development Tools: VS Code, phpMyAdmin, Composer
* Version Control: GitHub

Why the Website Cannot Be Viewed Directly Online?

Currently, the project is developed using XAMPP, which acts as a local server (localhost) on the computer. Therefore, the website can currently be accessed only from the computer where XAMPP and the project are running, using an address such as http://localhost/.... It is not yet deployed on a public web server, so others cannot access the website through a normal internet link at present.
